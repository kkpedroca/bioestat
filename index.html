Teste de Kruskal–Wallis

Compare três ou mais grupos independentes quando não quiser assumir distribuição normal.

Digite os valores separados por vírgula, espaço ou quebra de linha. Cada campo representa um grupo independente.

Resultado

Insira os dados e clique em “Calcular” para visualizar o resultado.
O teste avalia se há evidências de diferença entre pelo menos dois grupos. Um resultado significativo não identifica, sozinho, quais grupos diferem; para isso, use um pós-teste apropriado.

Teste de Shapiro–Wilk

Verifique se uma amostra é compatível com uma distribuição normal.

Informe pelo menos 3 observações. Separe os valores por vírgula, espaço ou quebra de linha.

Resultado
